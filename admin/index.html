Редактор меню — Izakaya

Изменения сначала сохраняются только на вашем устройстве. Чтобы обновить сайт, скачайте файл и загрузите его в GitHub. Для публикации нужен доступ к репозиторию. Пароль и токен здесь не вводятся.

Открыть загрузку в GitHub

После загрузки замените существующий menu.json, нажмите Commit changes и дождитесь обновления сайта.
