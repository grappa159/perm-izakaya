Редактирование сайта

Изменения сохраняются через GitHub. Для редактирования войдите в аккаунт с правами на репозиторий этого сайта. Данные доступа вводятся только на GitHub.

Изменить меню и цены ↗Открыть файл menu.json в редакторе GitHub.Изменить текст и контакты ↗Открыть страницу в редакторе GitHub.Загрузить фотографии ↗Добавить файлы в репозиторий. Чтобы заменить изображение на сайте, также измените его имя в index.html.

Сохраните изменения кнопкой Commit changes. Сайт обновится после сборки GitHub Pages. В меню сохраните структуру JSON: кавычки, запятые и скобки.
